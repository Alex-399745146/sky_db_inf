# sky_db_inf

---
**Курсовая работа**

Небольшое консольное приложение на Python, которое получает данные о самолётах из публичных API (OpenSky + Nominatim), сохраняет их в PostgreSQL и показывает отчёты по странам и бортам. [web:191][web:192]

## Функциональность

- Читает список стран из `config/config.ini` или ручного ввода.
- Определяет границы страны по Nominatim (OpenStreetMap).
- Запрашивает самолёты в указанных границах через OpenSky API.
- Сохраняет данные в базу PostgreSQL (3NF).
- Показывает отчёты:
  - список стран и количество самолётов;
  - все самолёты с регистрацией, скоростью и высотой;
  - средняя высота полёта;
  - самолёты выше средней высоты;
  - самолёты с «домашней» регистрацией (по выбранным странам).

## Требования

- Python 3.13+
- PostgreSQL
- Установленные зависимости (через `poetry` или `pip`):  
  `psycopg2`, `requests`, `prettytable`, и др.

## Установка

1. Клонировать репозиторий:

   ```bash
   git clone <url_репозитория>
   cd sky_db_inf
   ```

2. Настроить виртуальное окружение и зависимости (пример с poetry):

   ```bash
   poetry install
   ```

3. Создать и отредактировать файл `config/config.ini` по примеру:

   ```ini
   [app]
   countries = Russia, Iran, France

   [db]
   dbname = db_sky
   user = postgres
   password = your_password
   host = localhost
   port = 5432
   ```

## Запуск

```bash
python main.py
```

Приложение:

1. При первом запуске автоматически выполнит полный `update` (пересоздаст БД и таблицы).
2. Спросит, какие страны использовать (Enter — взять из `config.ini`).
3. Спросит режим работы БД: `y` — очистить и заполнить заново, `n` — дополнять существующие данные.
4. Выведет отчётные таблицы в консоль.
